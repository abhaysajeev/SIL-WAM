{# Agent Config — the tab on the user form that sets a user up for the agent app. Deliberately NOT part of the users form payload. Two reasons, both from the code: * form_view.html's collectPayload() sweeps every .dv-input carrying a `name`, hidden tab or not — `display:none` sits on the panel, not the input. So these inputs have ids and no `name`, and are read by the JS below instead. * PUT /api/users/{id} applies exclude_none=True, so it can never set a field back to NULL — which is exactly what releasing a device is. Hence its own endpoint. Everything here talks to /api/agents. #}
